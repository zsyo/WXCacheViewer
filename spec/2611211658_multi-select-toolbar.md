# 列表页多选与批量导出/删除

## 需求

列表页长按视频进入多选模式，长按项自动选中，之后可继续点选其它视频，以便批量操作。底部悬浮一条半透明圆角工具条，从左到右五个图标按钮：全选/全不选（点击后图标与语义自动切换）、反选、导出、删除、退出选择。全不选后仍停留在多选模式，只有点击退出（或全部删除成功）才结束。

## 实现

### 状态

`GalleryUiState` 新增 `selectionMode`（是否多选）与 `selectedNames`（选中文件名集合），并提供 `allSelected` 派生属性。选择模式与选中集合分离，因此「全不选」清空集合时不会退出模式。

### ViewModel

- `startSelection` / `toggleSelection`：长按进入并选中、点击切换选中。
- `toggleSelectAll`：已全选则清空，否则全选，两种情况都保持多选模式。
- `invertSelection`：以当前文件列表为全集取反。
- `exitSelection`：退出并清空。
- `exportSelected` / `deleteSelected`：按选中集合批量执行，逐项捕获异常并统计成功/失败数量，统一用 Snackbar 汇总提示。导出后一次性通知媒体库扫描；删除后从列表移除，全部成功则退出多选，有失败则保留失败项继续选中。
- `withFiles`：载入/刷新后按当前排序重排，并把已不存在的文件从选中集合剔除。

### 界面

- 卡片改用 `combinedClickable`：普通模式点击播放、长按进入多选；多选模式点击与长按都切换选中。
- 多选时卡片右上角显示白色描边的圆形勾选徽标（选中为主色底 + 对勾），选中卡片加 2dp 主色描边。
- 顶栏在多选模式下把标题替换为「已选择 N 项」，避免切号误操作；返回键退出多选。
- 底部工具条为半透明 `surfaceVariant` 圆角胶囊，`navigationBarsPadding` 上浮 20dp；列表底部留 104dp 内边距避免最后一行被遮挡。
- 删除前弹二次确认对话框，说明将删除 N 个文件且不可恢复。

## 新增资源

- `ic_select_all`、`ic_deselect_all`、`ic_invert`、`ic_close`。
- 字符串：选择计数、全选/全不选/反选/退出、批量导出与删除的成功/部分成功/确认文案。

## 验证

- `assembleDebug`、`testDebugUnitTest`、`lintDebug` 全部通过。
- APK 经 MT 安装到设备。
- 需真机确认：长按进入多选并选中该项；点击其它项可加减选中；全选后按钮变为全不选图标，点击清空但不退出；反选结果正确；批量导出后 Movies/WXCacheViewer 出现全部视频；批量删除二次确认后列表同步移除；退出按钮与返回键均能结束多选。
