# 缓存文件列表加载

## 目标
从选中账号的 `finder/video` 目录读取缓存文件，分析头部类型、大小并按文件名排序。

## 方案要点
- `CacheRepository.listFiles()` 用一条 su 命令同时输出文件名、大小、前 32 字节十六进制。
- 若目标机 toybox 的 `stat -c %s` 不可用，自动降级为 `wc -c < file`。
- 解析时再次校验文件名白名单，非法行丢弃；头部交 `FileTypeDetector`；结果按文件名倒序。
- 用 Fake RootCommandExecutor 做 JVM 单测，覆盖解析与降级分支。

## 完成标准
`./gradlew testDebugUnitTest --tests "*CacheRepositoryTest"` 通过。
