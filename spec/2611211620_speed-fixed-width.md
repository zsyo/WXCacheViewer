# 倍速按钮固定宽度，避免进度条宽度抖动

## 问题

倍速按钮此前是「文字 + 内边距」的自适应尺寸，文案在 `1x` / `0.75x` / `1.25x` 之间变化时宽度随之变化。它位于进度条右侧同一行，进度条用的是 `weight(1f)`，于是每次切换倍速左侧滑块长度都会跳动。

## 实现

- 倍速由 `Text` 改为固定尺寸的 `Box`（52dp × 40dp，与右侧音量按钮 40dp 同高），文字在内部居中。
- 52dp 是按最长文案 `0.75x` / `1.25x`（5 个字符，`labelLarge` 14sp）留出的余量，同时能容纳 1.2 倍左右系统字体缩放；`maxLines = 1` + `softWrap = false` 保证不放行换行。
- 点击区域随盒子固定，不再随文案变化；循环切换逻辑不变。

## 验证

- `assembleDebug`、`testDebugUnitTest`、`lintDebug` 全部通过。
- APK 经 MT 安装到设备。
- 需真机确认：连续点击倍速在 0.5x / 0.75x / 1x / 1.25x / 1.5x / 2x 之间循环时，进度条左右边界应完全不动。
