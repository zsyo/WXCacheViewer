# 图片大图页：旋转按钮与点按隐藏工具条

## 需求

看大图时经常遇到两个问题：

- 手机横着拍的照片，在大图页里是躺着的，得歪头看。系统相册都带旋转，这里没有。
- 顶栏和底部信息条常驻，看构图时一直挡着边缘；视频播放页可以点一下隐藏，这边不行。

表情包（wxgf / GIF 动图）基本都是方形，即使长方形也没有旋转需求，所以这两项都只做在**静态图片**上。

## 旋转

- 右侧悬浮一个圆形按钮（与播放页横屏按钮同一位置、同一套半透明底），每按一次顺时针 90 度：
  0 → 90 → 180 → 270 → 0，`nextRotation` 用 `(current + 90).mod(360)` 收敛，越界或负数也不会跑飞。
- 角度按 `file.key` 存在 `mutableStateMapOf` 里：每张图各自记自己的角度，滑走再滑回来还是那个角度，
  也不会串到相邻的图片上。旋转只是临时查看状态，不写文件、不落盘，重新进预览就是正的。
- 只有 `JPEG / PNG / WEBP` 显示旋转按钮；`WXGF / GIF` 动图不显示，也不响应点按隐藏。

### 旋转不能让图片被裁掉

直接给 `AsyncImage` 挂 `graphicsLayer { rotationZ }` 只改绘制、不改布局：布局框还是 `fillMaxSize`，
转 90 度后宽高互换，长边会超出屏幕被裁掉。

做法是外层 `BoxWithConstraints` + `Modifier.requiredSize`：转 90 / 270 度时把布局框的宽高换过来
（宽 = 容器高、高 = 容器宽），再用 `graphicsLayer` 绕中心旋转。框换了以后 `ContentScale.Fit`
会按旋转后的方向重新等比缩放，转完正好铺满原来的可视区，不裁也不留多余的边。
旋转只作用在图片的绘制层，顶栏、底栏、旋转按钮本身都不跟着动。

## 显隐

- 顶栏（返回 / 文件名 / 导出）、底栏信息条、旋转按钮一起用 `AnimatedVisibility` 淡入淡出，
  一个 `chromeVisible` 控制，不做「几秒后自动隐藏」，只有再点一下才回来。
- 点按检测挂在每一页的图片容器上（`detectTapGestures`）：点图片或黑边都能切换；
  拖动翻页时 `detectTapGestures` 会按触点位移自行取消，不会把一次滑动误判成点击。
- 顶栏上的按钮、可长按的文件名都在更上层且消费了按下事件，页内 `detectTapGestures`
  默认 `requireUnconsumed = true` 会跳过这次手势，不会出现「点导出顺手把顶栏隐藏了」。
- 动图页保持原来的常显：`chromeShown = chromeVisible || !rotatable`。在图片页藏起来后滑到表情包，
  顶栏会回来，滑回图片又是隐藏状态。

## 验证

- `nextRotation` 单测：逐次 +90、满 360 回 0、连按四次归位、越界与负角度归一。
- `lintDebug` 无告警，四 ABI `assembleDebug` 通过，单测 155 条全绿。
- 真机：竖图横图各转四次回到原角度且不被裁切；旋转时顶栏与按钮位置不动；
  点图片能隐藏/唤回工具条；滑到表情包页顶栏常显且没有旋转按钮。
