# 缓存列表排序功能

## 目标
顶栏在视图切换按钮旁新增排序按钮，点击弹出下拉框，可分别选择排序字段（文件大小 / 修改时间）与排序方向（正序 / 倒序）。默认按修改时间倒序。

## 方案
- 模型扩展：`CacheFile` 增加 `modifiedAt`（Unix 秒，取不到时为 0）；新增 `SortField`（`SIZE`、`MODIFIED_TIME`）、`SortDirection`（`ASC`、`DESC`）与 `SortOption`（默认 `MODIFIED_TIME` + `DESC`）。
- 数据采集：`WxPaths.listFilesCommand` 在原有 `名称\t大小\t` 之后追加 `stat -c %Y` 的修改时间字段，再跟文件头十六进制；`CacheRepository.parseLine` 按 4 个字段解析，尺寸字段保持原 `stat -c %s`（stderr 不被吞掉），以便 `stat` 不可用时仍能触发 `wc -c` 回退。
- 排序：新增纯 Kotlin 的 `CacheFileSorter.sort(files, option)`，按字段比较后依方向反转，取值相同时统一按文件名升序保证稳定；`CacheRepository.listFiles` 不再硬编码排序。
- 状态与持久化：`SettingsRepository` 增加 `sortField` / `sortDirection`（默认修改时间 + 倒序）；`GalleryUiState` 增加 `sortOption`，`GalleryViewModel` 初始化时从偏好读取，`setSortOption` 立即重排当前列表并写回偏好，不重新读盘。
- UI：顶栏 `actions` 中视图按钮前插入排序 `IconButton`（新增 `ic_sort.xml`），点击展开 `DropdownMenu`，内含"排序方式""排序方向"两个分组，每项用 `RadioButton` 表示当前选中项；选择后即时生效并关闭菜单。

## 完成标准
`assembleDebug` 与 `testDebugUnitTest` 通过（新增 `CacheFileSorterTest` 5 个用例，覆盖默认倒序、时间正序、大小正/倒序、等值回退）；真机点排序按钮可切换四种组合，列表顺序随之变化，重启应用后保持上次选择。
