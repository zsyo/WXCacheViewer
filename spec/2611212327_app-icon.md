# 应用图标

## 目标
项目此前没有配置 `android:icon`，用的是系统默认图标。把设计稿 `art/app-icon-source.png`（1254×1254，RGBA，透明底）加工成完整的 Android 图标资源，启动器里显示为自适应图标。

## 素材分析
- 画布 1254×1254，透明背景；不透明内容边界 `x 49..1221`、`y 79..1171`，即 1173×1093（宽高比 1.07:1），画布四周留白不均，先按边界裁掉再用，缩放比例才可控。
- 内容偏「满铺」构图：左上绿色气泡、右上白色气泡、中间橙色文件夹（含图片/视频/语音/文档四个小图标）、右下放大镜、四周有绿色光带。

## 方案要点
- **自适应图标（API 26+）**：`mipmap-anydpi-v26/ic_launcher.xml` 用 `background`（矢量渐变 `drawable/ic_launcher_background.xml`，上白 `#FFFFFF` 到下浅薄荷 `#E9F5EC`）+ `foreground`（位图）两层。
- **前景安全区**：图案最大边取画布 60%（108dp 中约 64.8dp），落在 66dp 安全圆内；试过 55% 偏小、65% 时右下放大镜手柄与底部光带会被圆形遮罩切到，60% 是兼顾饱满与安全的取值。
- **旧版图标（API 24/25）**：`mipmap-*dpi/ic_launcher.png` 为带渐变底的方形位图，图案占 82%。
- 密度齐全：`mdpi 48/108`、`hdpi 72/162`、`xhdpi 96/216`、`xxhdpi 144/324`、`xxxhdpi 192/432`（前者旧版图标边长，后者自适应前景边长）。
- 清单同时设置 `android:icon` 与 `android:roundIcon`，都指向 `@mipmap/ic_launcher`；圆形图标交给启动器的遮罩处理，不额外做圆图。
- 不加 `monochrome` 层：图案是彩色插画，压成单色剪影会失去辨识度。
- 加工用 ffmpeg（`crop` → `scale=lanczos` → `pad`/`overlay`），源图归档在 `art/app-icon-source.png`，以后重做按本文参数重跑即可。

## 完成标准
- 启动器、最近任务、设置里的应用信息都显示新图标，圆形/方形遮罩下主要内容不被裁切。
- `assembleDebug`、`lintDebug` 通过，APK 内 `res/mipmap-*` 与 `mipmap-anydpi-v26` 资源齐全。
