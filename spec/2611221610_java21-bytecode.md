# 字节码目标提升到 Java 21

## 背景
运行环境已升到 JDK 25 LTS。项目全 Kotlin，无 Java 源文件；Kotlin 2.4.21 编译器支持 `JvmTarget.JVM_21`。D8/R8 对 class 65（Java 21）的处理已成熟，风险显著低于直接升到 class 69（Java 25）。

## 方案
- `app/build.gradle.kts`：`sourceCompatibility` / `targetCompatibility` 改为 `JavaVersion.VERSION_21`，Kotlin `jvmTarget` 改为 `JvmTarget.JVM_21`；注释说明与运行 JDK 25 解耦，不跟到 25 以控制脱糖与 R8 风险。
- `README.md`：构建环境说明同步为字节码目标 Java 21。
- 源码不改：不引入 Java 源文件，不使用 `SequencedCollection`、虚拟线程等在 `minSdk 24` 上不可用的新 API；继续用现有的 `data class`、`sealed interface`、`when`、`entries`、协程等 Kotlin 写法。

## 验证
- `javap -verbose` 查看 Kotlin 编译产物 `major version` 为 65。
- `:app:testDebugUnitTest :app:lintDebug :app:assembleRelease` 全过；release 经 R8 处理 class 65 无异常。
- 四 ABI APK 签名与 16KB 页对齐校验通过。

## 回退
把 `compileOptions` 与 `jvmTarget` 改回 17，并同步 README。
