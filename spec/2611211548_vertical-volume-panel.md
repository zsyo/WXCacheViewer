# 播放控制层布局调整：倍速/音量并入进度条右侧，音量改为垂直弹出

## 背景

原控制层底部为三行结构：

1. 音量面板（水平滑块，位于进度条上方，展开时把进度条整体顶上去）
2. 进度条行（当前时间 + 滑块 + 总时长）
3. 倍速文字按钮（左）与音量图标（右）

水平音量条展开会挤占进度条行的高度，且音量图标与滑块分离在两行，操作路径不直观。

## 目标

- 倍速与音量按钮并入进度条同一行，位于进度条右侧。
- 点击音量按钮后，音量滑块以**垂直形式**出现在音量按钮**正上方**（播放器常见形态），不再出现在进度条上方。

## 实现

### 布局

底部控制层由 `Column` 三行简化为单个 `Row`：

```
[当前时间] [进度滑块 weight(1f)] [总时长] [倍速] [音量图标]
```

- 倍速由 `TextButton` 改为可点击 `Text`（去掉 Material 默认大内边距，避免挤压进度条），仍点击循环切换 0.5x/0.75x/1x/1.25x/1.5x/2x。
- 音量按钮为 40dp `IconButton`，音量为 0 时图标半透明提示静音。

### 垂直音量面板

- 用 `Popup` + 自定义 `PopupPositionProvider`：`anchorBounds` 取音量按钮所在 `Box` 的边界，弹层水平居中对齐按钮、垂直方向位于按钮上方并留 6dp 间距，超出屏幕时向窗口内收敛。
- 面板内容：顶部百分比文字 + 垂直滑块 + 底部音量图标，深色圆角底，非 focusable 弹层不抢焦点。
- 垂直滑块自绘（40dp 宽触摸区 + 4dp 轨道 + 14dp 圆形滑块），用 `detectTapGestures` 点按定位、`detectDragGestures` 拖动跟随，按 y 坐标换算音量档位。
  - 没有采用「旋转水平 `Slider`」的做法：旋转后布局边界不随之交换，容易在弹层窗口中产生裁剪，且触摸区域不直观。
- 每次展开面板前重新读取系统媒体音量，避免外部调音量后显示不同步。

### 自动隐藏

- 控制层自动隐藏的 `LaunchedEffect` 增加 `volumePanelVisible` 判断：音量面板打开期间不自动隐藏，避免拖到一半控制层消失。
- 控制层被隐藏时同步关闭音量面板。

## 验证

- `assembleDebug`、`testDebugUnitTest`、`lintDebug` 全部通过。
- APK 经 MT 安装到设备。
- 需真机目测：音量面板是否恰好贴在按钮上方、垂直拖动是否跟手、进度条右侧两个按钮是否被挤出屏幕。
