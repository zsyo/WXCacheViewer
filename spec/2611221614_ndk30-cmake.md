# 升级 NDK 至 r30 与 CMake 至 4.1.2

## 背景
NDK r30（30.0.16248370）是当前稳定 LTS，sysroot API 提升到 37，与项目 compileSdk 37 对齐；Android SDK manager 可安装的 CMake 最新稳定版是 4.1.2。AGP 9.5 默认仍是 NDK 28.2.13676358 / CMake 3.22.1，但不限制显式配置其他版本。

## 方案
- `gradle/libs.versions.toml`：`ndk` 改为 30.0.16248370，`cmake` 改为 4.1.2。
- `.github/workflows/release.yml`：SDK 包串同步为 `ndk;30.0.16248370 cmake;4.1.2`，仍保持一行。
- `app/build.gradle.kts`：NDK 注释改为 r30 默认 16KB 对齐，CMake 链接参数保留。
- `README.md`：CI 与 16KB 说明同步。
- `app/src/main/cpp/CMakeLists.txt` 不改：`cmake_minimum_required(VERSION 3.22.1)` 对 CMake 4 合法；`-Wl,-z,max-page-size=16384` 保留作防退化保险。

## 验证过程
1. 先以 CMake 3.31.6 建立基线：安装 NDK 30 + CMake 3.31.6，四 ABI `assembleRelease` 通过。
2. 再切 CMake 4.1.2：安装后重复四 ABI `assembleRelease`，通过。
3. 四个 APK 均 `zipalign -c -P 16 4` 通过、`apksigner verify` 通过。
4. 从四个 APK 解出 `libwxsilk.so`，`llvm-readelf -lW` 的 LOAD 段 `Align` 全部为 `0x4000`。

## 回退
CMake 4.1.2 若出现策略错误，回退到 3.31.6；NDK r30 若触发老 C 代码兼容问题，回退到 28.2.13676358，并保留显式 16KB 链接参数。
