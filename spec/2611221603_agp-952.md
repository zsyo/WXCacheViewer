# 升级 AGP 到 9.5.2

## 背景
`spec/2611220132_toolchain-upgrade.md` 记录时 9.5.1 尚未发布；Google Maven 现已发布 9.5.1 与 9.5.2，9.5.2 是当前稳定补丁。AGP 9.5.0 已修复 JDK 25 下 `generateReleaseRFile` 告警，9.5.2 继续修复补丁问题。

## 方案
- `gradle/libs.versions.toml`：`agp` 从 9.5.0 改为 9.5.2。
- `README.md`：技术栈版本同步。
- `spec/2611220132_toolchain-upgrade.md`：补充当时的版本判断已过期，指向本规格；不改写其余历史记录。
- Gradle 9.9.2、Kotlin 2.4.21、compileSdk 37 等保持不变。

## 验证
- `JAVA_HOME=E:/Dev/LibericaJDK`，`GRADLE_OPTS=--enable-native-access=ALL-UNNAMED`。
- `:app:testDebugUnitTest :app:lintDebug :app:assembleRelease` 全过。
- `generateReleaseRFile` 无告警。

## 回退
把 `agp` 改回 9.5.0，并同步 README 与 spec 说明。
